# LINDUNG Gen-Z Leaders Camp 2026

Laman GitHub Pages untuk LINDUNG Gen-Z Leaders Camp 2026 (1–5 Disember 2026, Pusat Rehabilitasi PERKESO Tun Abdul Razak, Ayer Keroh, Melaka). Anjuran bersama PERKESO dan SOSCoE, SBM Universiti Utara Malaysia.

- Laman: https://lgzcamp.github.io/
- Google Site rasmi: https://sites.google.com/view/uumsocso
- Borang pendaftaran: https://forms.gle/Bf7atdziwt3wAxjGA (tutup 22 Nov 2026, 6.00 ptg)
- Kehadiran peserta : https://lgzcamp.github.io/attendance/
- Modul peserta (berkata laluan, StatiCrypt): https://lgzcamp.github.io/modul/ · QR: `assets/qr-modul.png`

## Struktur
- `index.html`: satu halaman (HTML, CSS dan JS dalam satu fail)
- `assets/`: gambar Pusat Rehabilitasi, logo, lambang LGZ, kod QR dan poster

## Kemas kini
Sunting `index.html` terus di GitHub (ikon pensel), kemudian Commit. GitHub Pages akan terbit semula dalam 1–2 minit.


## Modul peserta (`modul/`)
`modul/index.html` disulitkan dengan StatiCrypt (AES-256). Kandungan tidak boleh dibaca tanpa kata laluan, walaupun kod sumber dibuka. Jangan sunting fail ini di GitHub; minta versi baharu dijana semula daripada sumber asal. `robots.txt` meminta enjin carian tidak mengindeks `/modul/`.
